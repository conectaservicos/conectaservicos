CONECTA SERVIÇOS - VERSÃO PWA

Arquivos:
- index.html: aplicativo original atualizado
- manifest.json: configuração de instalação do app
- service-worker.js: cache e funcionamento mais estável
- register-pwa.js: ativação do service worker
- icons/: ícones do aplicativo

PUBLICAÇÃO:
Envie todos estes arquivos para a raiz do repositório do GitHub Pages.
Depois abra o endereço HTTPS do GitHub Pages no Android ou iPhone.
Android: use a opção Instalar aplicativo/Adicionar à tela inicial.
iPhone: Safari > Compartilhar > Adicionar à Tela de Início.
